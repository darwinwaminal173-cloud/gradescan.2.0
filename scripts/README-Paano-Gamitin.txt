========================================================
           SMARTGRADE - OMR SCANNER & CHECKER           
========================================================

PAANO ITO GAMITIN SA COMPUTER / LAPTOP:
1. I-extract o i-unzip ang folder na ito.
2. I-double click ang file na: "Run-SMARTGRADE.bat"
3. Awtomatikong magbubukas ang iyong browser sa SMARTGRADE app!
4. Walang kailangang i-install na Node.js o iba pa! Ready-to-use na ito!

PAANO I-BUILD ANG ANDROID APK (CLOUD BUILDER - 90 SECONDS):
1. Gumawa ng libreng account sa GitHub (https://github.com) kung wala pa.
2. Gumawa ng bagong repository na may pangalang "smartgrade".
3. I-upload ang laman ng "SMARTGRADE-SourceCode.zip" o i-push gamit ang Git.
4. Pumunta sa tab na "Actions" sa iyong GitHub repository.
5. Makikita mo ang workflow na "Build SMARTGRADE Android APK".
6. Pindutin ang "Run workflow" -> "Run workflow".
7. Sa loob ng 90 seconds, tapos na ang cloud build!
8. Pindutin ang natapos na build run at i-download ang:
   "SMARTGRADE-Android-APK" (ito ang mismong APK file na ini-install sa Android phone!)
